# Oracle Card Ideas (Future)

Ideas for oracle cards beyond the initial v1 set. These could be added later to increase variety.

| Name | Requires | Reveals |
|------|----------|---------|
| **Void Scanner** | Player | "Player X is void in [suits] / has no voids." |
| **Suit Leader** | Suit | "Player X has the most [suit] cards (N)." |
| **Ace Locator** | Suit | "The [suit] Ace is held by Player X." |
| **Trump Power** | Suit | "The hidden players hold N total [suit] cards." Combined total only — no per-player breakdown. |
| **Partner Peek** | — | Reveals 3 random cards from your partner's hand (player 2). |
| **Danger Scan** | Suit | "Player X has the highest [suit] card (rank)." Which opponent holds the top card in a suit. |
| **Suit Split** | Suit | Shows distribution of a suit across all 4 players: "Red: 3-4-2-4" |

### Notes

- Some of these need two choices (player + suit). If we stick with the one-choice-per-oracle rule, they'd need to be split into variants (like we did with Suit Count) or have one parameter baked in at draw time.
- Partner Peek needs no choice at all — could work as a zero-choice oracle for variety.
- Suit Split gives a lot of information for one oracle use — might need to be rare or cost 2 oracle uses.
